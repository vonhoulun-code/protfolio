# VON — 冯皓龄个人设计作品集预览

静态单页作品集，用于确认设计方向。姓名英文暂用 HAOLING FENG，顶部标识为 VON。

代码仓库：https://github.com/vonhoulun-code/protfolio 。网站文件位于 `dist/`，可直接由静态托管服务提供，无需安装依赖或构建。上传代码与启用 GitHub Pages 是独立步骤；本仓库保存网站完整源码，GitHub Pages 尚未启用。

## 当前设计

- 黑色窄边框、圆角首屏、顶部凹口内的 VON 字标。
- 原创 WebGL 深蓝流光：鼠标移动增强局部亮度、光泽与扭曲，停止移动后渐弱；保留原生鼠标。
- 居中英文小字姓名、细横线、INDEPENDENT DESIGNER；下方中文自述突出好奇心、学习和认真创作。
- 六个明确标注的概念示例，桌面双列、移动端单列瀑布流，6px 间距与圆角；悬停轻微放大、滚动渐入。
- 首页流光默认自动开启，无播放/暂停按钮；无 WebGL 时显示静态蓝色渐变；首屏离开视口或标签隐藏时停帧，重新可见时自动恢复。系统减少动画设置仍用于作品渐入和 CSS 过渡。
- 无数据库、表单、API、联系人数据或外部依赖。

## 本地预览

在项目根目录执行 `node preview-server.mjs`，访问 http://127.0.0.1:4173 。仅监听本机。

此地址依赖本机预览进程持续运行；进程退出或电脑重启后需要重新启动。2026-09-16 出现连接被拒绝时，已确认原服务停止，并以隐藏的后台 Node 进程恢复服务；随后验证 HTTP 200 和浏览器页面正常。

验证命令：`node --check dist/app.js`、`node --check preview-server.mjs`、`node --test tests/portfolio.test.mjs`。
